# Apk

تم إنشاء لعبة Godot من نوع Free Kick Football داخل المشروع.

المتطلبات:
- Godot 4.x
- افتح project.godot
- اضغط Run

التحكم:
- A / D: ضبط زاوية التسديد
- W / S: ضبط قوة التسديد
- Space: تنفيذ الركلة الحرة

لعبة جاهزة للتشغيل، مع واجهة بسيطة وأداء بصري جيد باستخدام ألوان وتدرجات وممرات الملعب.
