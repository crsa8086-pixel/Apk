# Free Kick Legends 3D

مشروع لعبة ركلات حرة **ثلاثية الأبعاد** باستخدام Godot 4، مع ملعب ومجسمات 3D وإضاءة وظلال وكاميرا منظور.

## التشغيل
1. افتح مجلد المستودع من Godot 4.
2. افتح `project.godot` واضغط **Run**.

## التحكم
- **A / D** أو الأسهم يمين/يسار: توجيه التسديدة
- **W / S** أو الأسهم أعلى/أسفل: زيادة/تقليل القوة
- **Space**: تنفيذ الركلة
- **R**: إعادة النتيجة

يتضمن المشروع ملعباً ثلاثي الأبعاد، مرمى وشبكة، مدرجات، حارساً يتحرك نحو الكرة، كرة ذات مسار مقذوف، لوحة نقاط، ومؤشر تصويب.
