# Apk

Free Kick Legends — لعبة ركلات حرة في Godot 4.

المتطلبات:
- Godot 4.x
- افتح ملف project.godot
- اضغط Run

التحكم:
- A / D: توجيه الكرة
- W / S: ضبط قوة التسديد
- Space: تنفيذ الركلة

المميزات:
- ملعب احترافي بصرياً
- كرة متحركة مع ارتداد
- حارس مرمى يتبع الكرة بشكل حي
- نظام نقاط وHUD
- إعادة التشغيل تلقائي بعد الهدف أو الحفظ

ملاحظات:
- تم تحسين الواجهة والرسومات واللعبة بشكل أفضل من النسخة الأساسية.
